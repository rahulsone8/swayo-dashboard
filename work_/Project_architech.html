Extra Features (Detailed)
FeatureImplementation referenceDetailed explanationOperational benefit
Dark / Light ModeinitTheme(), applyTheme(), toggleTheme() in dashboard.jsTheme is initialized on load, saved in localStorage, and can follow system preference. UI tokens are switched without reloading data, so charts and tables stay intact.Comfortable day/night usage and less analyst fatigue.
Global filter contractfp() in dashboard.js + ordersWhere()/multiIn() in server.jsSingle query param builder on frontend; backend uses shared SQL helper, so all pages interpret filters consistently. This avoids page-to-page mismatch bugs.Reliable cross-tab comparisons.
Multi-select filter enginemulti-select UI helpers + multiIn()Platform/restaurant selections are serialized as comma-separated values then converted into SQL IN placeholders safely.Flexible segmentation with secure SQL.
Modal drilldownopenModal(), showDrillOrders(), /api/drillChart click opens order-level data behind aggregated metric. Drill inherits current global filters so context remains consistent.Fast root-cause investigation.
Export enginebuildExportQuery(), toCSV(), toExcel(), /api/export/*Preview-first approach reduces bad exports; final download supports CSV/XLS with typed formatting and headers.Operations-friendly data sharing.
Health indicator/api/health + db-dot status in navUI reflects DB/API status early; if failed, users immediately know backend is unhealthy before assuming chart logic is broken.Quicker incident triage.
Custom tooltip systeminitTooltip(), showTooltip(), hideTooltip()Single tooltip behavior for charts/cards/modals avoids browser-native inconsistencies and double tooltip bugs.Cleaner UX and fewer confusion points.
